# 남은 버그와 점검

기준: `make test` 통과(Rust 50, Swift 50, 선택 실행 각 2개 제외). 앱을 바꾼 뒤에는 `make engine`과 `make run`으로 엔진과 앱을 함께 다시 만든다.

## 수동 점검 (자동화하지 못함)

- [ ] 자동 저장과 창 닫기 저장: 입력·그림 이동 직후 닫고 다시 열어 같은지 확인.
- [ ] 실제 macOS 한글 입력기: 조합 중 ⌘A 후 입력이 전체를 교체하는지, 조합→확정→Undo가 한 단계인지.
- [ ] ⌘F: 캔버스에서, 글자 크기 칸에서, 이미 열린 찾기 막대에서 각각 눌러 검색 칸이 키보드를 받는지(수정했으나 화면에서 확인하지 못함).
- [ ] 복합 문자: 옛한글 자모, 결합 악센트, 아랍어, 이모지 ZWJ가 화면과 PDF에서 깨지지 않는지(빠른 글리프 경로를 이런 문자에서 비켜 가게 했으나 fixture가 없음).

## 남은 문제

| 순위 | 문제 | 메모 |
|---|---|---|
| P1 | 표 셀·글상자·각주·머리말 안 그림을 삽입·선택·크기 조절할 수 없음 | `ObjectRef`가 본문 문단 번호만 가리킴(`objects.rs`가 `cellIdx`, `cellPath`, `noteRef`, `headerFooter` 개체를 제외, 앱도 셀에서 그림 삽입을 거부). 셀 경로를 담도록 확장 필요. ROADMAP 1단계 |
| P1 | 편집 실패가 경고음으로만 끝남 | `HwpDocument.enqueue` 등. 앱 안에 설명 문구를 넣지 않는 원칙과 맞물려 표시 방식을 먼저 정해야 함. 문서가 잠기면(`Locked`) 편집 도구를 미리 끄는 것부터 |
| P2 | 크기 고정 개체의 조절점이 그대로 보임 | 엔진은 크기 고정 개체의 크기 변경을 거부함(적용됨). 조절점 숨기기는 배치 정보에 `sizeProtect`를 실어야 함 |
| P2 | 표·셀·본문 경계를 넘는 선택 | 엔진이 거부함. 끌기 선택을 현재 컨테이너 경계에서 멈추게 하는 것이 단기 방안 |
| P3 | 그림 모서리 조절의 비율 유지가 Shift일 때만 | 한컴 동작과 macOS 관례 중 정할 것 |

## 해결한 것 (참고)

저장 장벽, 한글 조합 확정, 프로토콜 버전 2, 잘라내기 선택 확인, 검색 결과 역전 방지, 찾기 막대 포커스 재요청, 복합 문자 경로, 크기 고정 거부, 화면 의존 배율 테스트. 회귀 테스트는 `Tests/DocumentTests.swift`, `Tests/EditSessionTests.swift`, 엔진 `editing/tests.rs`.
